The Intellectual Frontiers guide

How the public root works, and how to work in it. One command line, agora, runs every check, build and record. It needs only Python and uv on your machine.

Start

Install Python 3.11 or later and uv, clone the repository, and ask the command line to teach you. The daily work is explained in one place, in the program, and in VS Code every step is a button.

./agora doctor
./agora help start
./agora check --suite spec
