**Color rules:**
- Use Deep Ink for the IP identifier and as the neutral color for the
  corporate wordmark and most text. Deep Ink is not a separate corporate arm.
- Use unit colors as identifiers, not as large decorative floods.
- Keep the core graphic's four colors in the approved arm assignment.
- On dark fields, use white typography. Use the full-color graphic only when
  every arm remains distinct.
- For one-color production, use all Deep Ink on light backgrounds or all
  white on dark backgrounds.

## Naming architecture

| Level | Naming | Rule |
| --- | --- | --- |
| Corporate | Intellectual Frontiers | Use the corporate two-line lockup without a descriptor. |
| Operating unit | Intellectual Frontiers Capital / IP / Press / Studios / Network | Append the unit name after Frontiers on line two in its assigned color. |
| Program or product | Descriptive name endorsed by the relevant unit | Keep the program name outside the logo. Use "from" or "by" language in copy. |
| Legal entity | Full legal name where required | Use LLC and other legal suffixes in contracts and notices, never inside the logo. |

**Extension rules:**
- Place new work under Corporate, Capital, IP, Press, Studios, or Network
  before creating another brand.
- Use the existing unit color when an extension belongs to a unit.
- Do not add another arm, recolor the corporate graphic, or create a separate
  symbol for a program.
- A fifth peer unit, Network, is now permanent. The whole architecture is
  under review before another arm or color is added to the graphic.

**Naming rules:**
- Use the full name on first external reference: Intellectual Frontiers
  Capital, IP, Press, Studios, or Network.
- Use Capital, IP, Press, Studios, or Network alone only after context is
  established.
- Do not rename the company "What IF?" or add a question mark to the
  approved mark.
- Do not recreate the logo with typed text. Use the supplied SVG artwork.

**Backgrounds:**
- White and Warm Paper are preferred.
- Use the full-color mark on quiet, high-contrast backgrounds only.
- On photography, place the logo in a clear field rather than over visual
  detail.
- Use the one-color white version when a dark background compromises the
  unit colors.

**Do not:**
- Rotate further, flatten, stretch, crop, outline, bevel, animate, or redraw
  the mark.
- Change dot sizes, positions, arm assignments, or color order.
- Add gradients, transparency, lighting, or effects beyond the approved
  shallow depth and shadow.
- Move the unit name to another line or detach it from the parent name.
- Use the retired single-line lockup.
- Place taglines, program names, legal suffixes, or "What IF?" inside the
  logo.

## Voice

| Principle | Write | Avoid |
| --- | --- | --- |
| Evidence-led | State the evidence, assumption, and decision. | Unsupported claims and narrative certainty. |
| Practical | Name the smallest useful experiment and the next decision. | Large plans without a testable wedge. |
| Skeptical | Say what would prove the claim wrong. | Advocacy dressed as analysis. |
| Plain | Use specific nouns, active verbs, and short sentences. | Consulting jargon, AI hype, and promotional adjectives. |

This applies to any AI-assisted drafting done in this repository or on
Intellectual Frontiers' behalf, not only human-written copy.

The four principles above are the summary. The full writing guide —
first-person vs. corporate point of view, banned vocabulary, the audit
pass, and the ASD-STE100 switch for procedures — is
[`context/writing-guide.md`](writing-guide.md).

**Questions any brand-facing material should be able to answer:**
1. What unusual advantage is already present?
2. Why does this person or organization have it?
3. Who cares enough to spend a scarce resource?
4. What is the smallest experiment that can prove or disprove value?
5. What makes the advantage difficult to copy?
6. If successful, how does each use strengthen the next one?

## Asset handling

- SVG is the source format for logos. Use PNG only when the platform does
  not accept SVG.
- Export raster artwork from the approved SVG; do not use screenshots or
  copied web images.
- Preserve transparent backgrounds and adequate resolution.
- Do not edit master artwork inside presentation, social media, or page
  layout tools.
