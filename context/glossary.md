# Glossary

> **Status: canonical.** Defined terms used across this repository. If a
> spec or context file uses one of these terms, it means what's defined
> here — a downstream spec should cite this file rather than quietly
> redefining a term. Terms are grouped by where they're mostly used, not
> strictly alphabetical, since most of them only make sense next to their
> neighbors.

## Company-wide

- **Native Alpha** — an unusual, disproportionate advantage that already
  exists and is strong enough to change a real decision. Not a patent, a
  clever idea, expertise, relationships, or AI use by itself — those may
  contribute to it, but only evidence proves it. See constitution §3.
- **The evidence chain** — Observation → Possible Native Alpha → Who
  cares → Cheapest credible test → Evidence.
- **The decision checkpoint** — the five honest options at any stage:
  continue, change the thesis, back someone else, build it ourselves, or
  stop. "Back someone else" is checked before "build it ourselves." See
  constitution §6.
- **The evidence taxonomy** — what each unit's activity produces: a
  patent produces IP evidence, a publication produces audience evidence,
  a customer experiment produces demand evidence, and so on, all feeding
  back into one Native Alpha thesis. See constitution §6.
- **Search before build** — the rule that Studios doesn't build toward a
  thesis until a search (via IF Network or the broader market) for an
  existing founder or company pursuing it credibly has come up empty. See
  constitution §6.
- **Shared services** (back-office sense) — legal, finance and
  accounting, compliance, and general operations, routed to independent
  providers the same way for every unit; not to be confused with Studios'
  own portfolio-facing shared services below. See constitution §7.
- **The hiring rule** — full-time hiring only for work that is steady,
  strategically important, financially sound, and supported by at least
  18 months of runway.
- **Unit boundary** — the rule that no unit's activity proves another
  unit's claim: a patent doesn't prove a venture, a publication doesn't
  prove demand, Studio activity doesn't justify investment, investment
  doesn't prove product-market fit.

## IF IP

- **Research area** — the top of IP's chain; groups related work.
- **Research pillar** — a standing line of inquiry under a research area,
  with a stated question and recorded findings.
- **Defensive disclosure** — a deliberate publication that keeps a method
  usable rather than excluding others from it — the opposite move from
  filing a patent on the same finding.
- **IPLG (Intellectual Product-Led Growth)** — IF IP's model for turning
  research and frameworks into things a reader can use directly
  (Executable Content) rather than only read about, so usage itself
  becomes evidence.
- **Executable Content** — a prompt, worksheet, assessment, or scorecard
  that makes a research finding or framework directly usable.

## IF Press

- **A Fieldbook** — one of the four named books carrying the Intellectual
  Frontiers Press imprint.
- **The publishing evidence ladder** — silence, argument, adoption of
  terminology, and willingness to pay, in ascending order of how strongly
  each confirms a thesis.
- **Founder writing** — Shahid Shah's own writing, published externally,
  curated by type: Contrarian Brief, Design Pattern, Working Theory,
  Practitioner Journalist.

## IF Capital

- **Care Delivery Fund I** — proves that a set of reimagined
  care-delivery pieces work together; deliberately narrow in scope.
- **Care Delivery Fund II** — backs clinician-led care-delivery companies
  through one of three modes: invest, take selective control, or build.
- **Capital as a search function** — Capital's role in actively looking
  for an external founder or company already pursuing a thesis, before
  funding a competing internal build.
- **Capital sources** — the firm's own balance sheet, and LPs and
  investors brought in through IF Network.

## IF Studios

- **Venture Architecture** — the work of deciding what should exist and
  what proof earns more time or money.
- **The Venture Development Lifecycle** — Observe → Frame → Validate →
  Experiment → Paid proof → Repeat → Independence.
- **The independence test** — a single binary judgment (could a qualified
  replacement continue this tomorrow on company-controlled records,
  rights, systems, and relationships?), deliberately not a scored
  checklist.
- **A design partner** — defined by five requirements (workflow access,
  an executive sponsor, a real scarce contribution, a non-demo data or
  implementation environment, a credible path to a commercial decision) —
  not friendliness or interest alone.
- **Shared services** (Studios sense) — Demand Engineering, Revenue
  Engineering, and Companion Executable Source Code Repositories: services
  built to stand alone and usable by every venture in the portfolio. Not
  to be confused with the company-wide back-office shared services above.
- **AI First / AI Augmented / AI Workforce** — naming tiers for a shared
  service, tied to how much human production work it still requires. "AI
  Workforce" is reserved for a service that genuinely doesn't need humans
  in the daily production loop.

## IF Network

- **A hunt** — a search with a written thesis, qualifying and
  disqualifying criteria, watched signals, running counts, and what it
  has learned so far.
- **An evidence packet** — the record on one candidate: who they are, why
  they surfaced, the signals, the Native Alpha hypothesis, sourced
  evidence, relationship path, named unknowns, next action, a confidence
  level, and a status.
- **The twelve-stage lifecycle** — Thesis → Discovery → Surfaced →
  Evidence → Human judgment → Contact → Conversation → Validation → Match
  → Experiment → Outcome → Learning.
- **Relationship memory** — the compounding record of who did what and
  how it turned out, queried in plain language through Ask Network.
- **The intelligence layer** — Network's role relative to the internet:
  the internet is the database of public information; Network knows whom
  to find, when, and why they matter to a specific thesis.
