# ArcaDrive releases

The newest version is listed in [`latest.json`](latest.json). Download `ArcaDrive-<version>-windows-x64.exe` from the folder of that version and run it: it is one file, needs no installer and no zip.

Windows may show "Windows protected your PC" because the program is not yet signed with a company certificate: choose **More info**, then **Run anyway**. Each file is also checked by ArcaDrive itself before it updates (SHA-256 and an Ed25519 signature listed in `latest.json`).
