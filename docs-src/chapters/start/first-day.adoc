== Your first day

You need one thing on your machine, https://docs.astral.sh/uv/[uv]. There is no `make install` and no environment to prepare. The first time you
run `./agora`, `uv` fetches `archon`, the command runner that every Intellectual Frontiers command line shares, and `archon` fetches everything the command
needs: the newest Python (3.14), the Python packages, and any program outside Python such as a typesetter or a browser. For a program it uses one already on your
machine when its version is new enough, otherwise your package manager's, otherwise a download it checks against a fixed fingerprint before it unpacks anything.
You are never asked to install a tool.

----
  you, an AI agent, or a CI job
              |
        ./agora  (a short launcher; needs only uv)
              |
           archon  --  who is there?  where does each program come from?
              |
   +----------+-----------+------------------+
   | your PATH | your package manager | a verified download |
   +-----------+----------+----------+--------------+
----

`archon` also works out by itself whether a person is there. At a terminal you see a spinner, colour and a progress bar for anything slow. An AI agent or a CI
job sees plain lines and is never asked a question. Either way the result is the same. <<orchestrator>> says how.

The first day is a handful of commands: see what is present, then run the checks. The help topic `start` gives them in order with what to expect from each: run
`./agora help start`, or open Learn in VS Code. The topic `check` says what to run before you push, and `recover` says what to do
when something fails. <<reference-help>> lists every topic.

`ws-host` is the friendlier environment for a person: it sets up a machine, clones the sibling repositories and runs VS Code with the Workspaces Console. It is a
convenience. Nothing here requires it.
