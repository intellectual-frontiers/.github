== Your first day

You need two things on your machine: Python 3.11 or later, and https://docs.astral.sh/uv/[uv]. There is no `make install` and
no environment to prepare. Everything else, from the Python packages to a typesetter and a browser, `agora` fetches into a cache
that belongs to you the first time a command needs it, checks against a fixed fingerprint before it unpacks anything, and uses
from there. It never uses a program it finds on your machine unless you name it.

The first day is a handful of commands: see what is present, install the system libraries once, fetch the toolchain, and run the
checks. The help topic `start` gives them in order with what to expect from each: run
`./agora help start`, or open Learn in VS Code. The topic `check` says what to run before you push, and `recover` says what to do
when something fails. <<reference-help>> lists every topic.

A prepared workspace is another way to set up a machine and clone the sibling repositories. It is a convenience. Nothing here
requires it.
