1. A plan implements one spec. Save it next to the spec it implements:
   spec-kit/specs/NNNN-kebab-case-slug/plan.md.
2. Fill in every bracketed field. Delete each guidance comment as you fill
   in the section it explains.
3. The Constitution Check is not a formality — it is the reason this
   template exists. A plan that can't pass it isn't ready to execute,
   whatever the spec says. Stop and resolve the gate, or get the plan's
   decision authority to sign off on the specific exception, before
   writing Phase 0.
4. A plan is not a spec. It doesn't restate requirements — it says how
   this specific attempt will try to satisfy them, with what evidence,
   on what budget, by when.
5. This template works whether what's being planned is a venture, a
   research program, a fund, a publication, or a search — spec-kit's
   phases are general-purpose; the Constitution Check is what makes them
   Intellectual Frontiers' own.

## Constitution Check

<!-- Work through every line before Phase 0. Check a box only when you can
name the specific answer, not when it feels generally true. -->

- [ ] **Native Alpha named.** What is the unusual, disproportionate
      advantage this plan is trying to prove or use? Write the sentence.
      If you can't, this plan isn't ready — see constitution §3.
- [ ] **Search before build.** If this plan builds something, has backing
      an existing founder or company been evaluated first, per
      constitution §6? Name who was checked, or why the check doesn't
      apply.
- [ ] **Unit boundary respected.** Does this plan cite another unit's
      activity (a patent, a publication, Studio activity, an investment)
      as proof of its own claim? If yes, stop — that's not allowed.
- [ ] **Evidence written down first.** Belief, smallest test, budget,
      decision date, evidence to continue, evidence to stop — all
      recorded before Phase 1 starts, per constitution §9.
- [ ] **Stop conditions named.** Which of the eight stop conditions
      (constitution §10) would end this plan, and how will each be
      checked?
- [ ] **Shared services respected.** Does this plan avoid standing up a
      unit-specific legal, finance, compliance, or operations function?
      Per constitution §7 / 0001 FR-028, these are shared, not rebuilt.
- [ ] **Decision checkpoint named.** Which of the five outcomes —
      continue, change, back someone else, build it ourselves, stop —
      does a good result lead to? Which does a bad one?

If a box can't be checked, this plan is not ready. Either resolve it, or
record the specific exception and who approved it under Complexity below
— never leave a box silently unchecked.
