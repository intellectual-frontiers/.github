# CourseStructure.xsd

The cmi5 course structure schema, copied unchanged from the AICC's cmi5 specification repository
(`AICC/CMI-5_Spec_Current`, branch `quartz`, `v1/CourseStructure.xsd`), under the Apache License 2.0. The harness
validates every built `cmi5.xml` against it (frontiers-course spec FR-016).
