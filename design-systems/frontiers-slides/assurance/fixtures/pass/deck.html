Write the test before you start

Stopping rules3

Name the metric, the date and the threshold

  • The metric is one number a skeptic would accept
  • The date is on the calendar before the kickoff
  • The threshold is what the metric must reach by then
Stopping rules4

Each of these is a decision the sponsor signs. If one is missing, the pilot has no way to end.
