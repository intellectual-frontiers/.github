Assurance

Tests that prove this design system does what its documentation says. This page is the harness, the report and the documentation, and it needs nothing but a browser.

Opened from file://

Browsers do not let a file:// page fetch files or inspect iframes, so the Integration suites and the stylesheet checks are skipped (never counted as passing). Unit tests of tokens and components still run. For everything, serve this design system's directory with any static server, for example python3 -m http.server, and open /assurance/.

How to use this

  1. In a browser, no setup: open assurance/index.html. Tests run on load.
  2. Everything, in a browser: serve the directory holding this design system and its brand (python3 -m http.server) and open /frontiers-console-web/assurance/. Add ?brand=example-brand to render it with another brand vendored beside it.
  3. Headless, for CI or a quick check: node assurance/run.mjs. It serves the directory holding this design system, runs this page in Chromium through Playwright and exits non-zero on any failure. --brand SLUG renders it with another brand; --shots DIR also writes screenshots of every fixture at 390, 900 and 1400 px.

Add ?suite=contrast to the URL to run only suites whose name contains that text, and ?manual to wait for the Run button.

What is guarded

This list is generated from the suites registered in unit.js and integration.js, so it cannot drift from what is actually tested.

Fixtures

Fixture pages are the test subjects and double as a living gallery. Each is a complete page written to chrome.md.

Adding a test

Register a suite next to its peers. A test is a function that throws on failure, so t.ok, t.equal, t.atLeast and friends are all you need. Mark anything that fetches or uses an iframe with needs: "http".

Assurance.suite("Cards", { group: "Integration", needs: "http", description: "Cards stack on phones." }, (s) => {
  s.test("two columns at 1280", (t) => withFrame("assurance/fixtures/home.html", { width: 1280 }, (f) => {
    t.equal(f.$$(".fc-card").length, 3);
  }));
});

A change to a design system's CSS, tokens, scripts or markup contract is complete only when this page is green over http.
