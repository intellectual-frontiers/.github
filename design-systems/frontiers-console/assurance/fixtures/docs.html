What this page shows

This is a fixture used by the assurance harness, and also the reference rendering of the docs layout. Resize the window: below 64rem the sidebar becomes a drawer, and the table of contents moves into a disclosure above the article.

Note

Everything here is plain HTML and CSS; the few web components in js/console.js only add behaviour.

Choosing a layout

Set data-layout on <fc-shell> to docs, notebook or home. Nothing else in the markup changes.

Health checks

Each check reports a status. Use a badge, never colour alone: passing warning failing.

Running tasks

Long-running work streams into a run log, described under Admin surfaces.

Development only

Task execution is gated by the deployment mode, never by what the page chooses to show.

Padding paragraph so the page is long enough to scroll and exercise the table of contents.
