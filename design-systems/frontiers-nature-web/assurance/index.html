Assurance

Tests that prove this design system does what its documentation says. This page is the harness, the report and the documentation, and it needs nothing but a browser.

Opened from file:// — browsers do not let a file:// page fetch files or inspect iframes, so the stylesheet checks and every Integration suite are skipped (never counted as passing). Unit tests of tokens and contrast still run. For everything, serve this design system's directory with any static server (for example python3 -m http.server) and open /assurance/.

How to use this

  1. In a browser, no setup: open assurance/index.html. Tests run on load.
  2. Everything, in a browser: serve the directory holding this design system and its brand (python3 -m http.server) and open /frontiers-nature-web/assurance/. Add ?brand=example-brand to render it with another brand vendored beside it.
  3. Headless, for CI or a quick check: node assurance/run.mjs serves the directory, runs this page in Chromium through Playwright and exits non-zero on any failure. --brand SLUG renders it with another brand; --shots DIR also writes screenshots of every fixture at 390, 900 and 1400 px.

Add ?suite=contrast to run only suites whose name contains that text, and ?manual to wait for the Run button.

What is guarded

Generated from the suites registered in unit.js and integration.js, so it cannot drift from what is tested.
