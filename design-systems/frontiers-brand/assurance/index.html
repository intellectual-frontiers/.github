Frontiers Brand

Assurance

Tests that prove this design system's tokens and logo files are what its spec says. This page is the harness, the report and the documentation, and it needs nothing but a browser.

Opened from file://: browsers do not let a file:// page fetch files or inspect iframes, so every test that reads tokens.json or a logo file is skipped (never counted as passing). Serve the directory holding this design system with any static server (for example python3 -m http.server) and open /frontiers-brand/assurance/.

How to use this

  1. Everything, in a browser: serve the directory holding this design system (python3 -m http.server) and open /frontiers-brand/assurance/.
  2. Headless, for CI or a quick check: node assurance/run.mjs serves the directory holding this design system, runs this page in Chromium through Playwright and exits non-zero on any failure.

Add ?suite=logo to run only suites whose name contains that text, and ?manual to wait for the Run button.

What is guarded

Generated from the suites registered in unit.js and integration.js, so it cannot drift from what is tested.

Fixtures

The specimen shows every brand colour, the typefaces and every logo file at its native size, on the background the spec allows it.
