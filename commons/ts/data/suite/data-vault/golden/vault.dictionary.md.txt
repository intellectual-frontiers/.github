| Column | Type | Null | Points to | Description | Personal data |
| --- | --- | --- | --- | --- | --- |
| hub_customer_id | TEXT | no |  | The key of the customer in the vault |  |
| customer_number | TEXT | no |  | The number the business knows the customer by |  |
| load_at | TIMESTAMPTZ | no |  | When the row was loaded |  |
| record_source | TEXT | no |  | Where the row came from: the system, file or feed |  |
