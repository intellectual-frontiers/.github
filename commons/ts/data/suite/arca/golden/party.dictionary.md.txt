## party

A party: anyone or anything a business deals with as one, whether a person or an organization. What is true of both is here; what is true of one only is in `person` or `organization`, under the same key.

Owner: arca. Primary key: (party_id).

| Column | Type | Null | Points to | Description | Personal data |
| --- | --- | --- | --- | --- | --- |
| party_id | TEXT | no |  | The party's key, a ULID the application makes. |  |
| party_kind_code | TEXT | no | party_kind.code | Whether the party is a person or an organization. |  |
| display_name | TEXT | no |  | The name the party is shown by, whatever its parts are. | PersonalData: Name |
| created_at | TIMESTAMPTZ | no |  | When the row was made |  |
| created_by | TEXT | yes |  | Who made the row |  |
| updated_at | TIMESTAMPTZ | yes |  | When the row was last changed |  |
| updated_by | TEXT | yes |  | Who last changed the row |  |
| deleted_at | TIMESTAMPTZ | yes |  | When the row was marked as removed |  |
| deleted_by | TEXT | yes |  | Who marked the row as removed |  |
