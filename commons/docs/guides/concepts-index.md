# Concepts

The ideas the repository is built on, each in a page you can read in a few minutes, with the specification that states it.

- [Mizan](concept-mizan.md): the format of specifications and the check that holds them.
- [Kanon](concept-kanon.md): the rule a library is built to: governance, logical, physical.
- [The ladder](concept-ladder.md): the architecture of a harness as rungs.
- [Standards first](concept-standards-first.md): never invent what a standard already names.
- [Releases (IFR)](concept-ifr.md): identity, version, edition and release are different things.
- [The quality system (IFQS)](concept-ifqs.md): what is true is what the system reports when it runs.
- [Capabilities configuration (IFCCM)](concept-ifccm.md): how change is controlled.
- [Lenses](concept-lenses.md): how this site documents layered models and programs.
- [The workbench](concept-workbench.md): what a person or an agent needs to do their job, declared once and prepared for each harness.
- [Workload](concept-workload.md): a unit of operated work, not running software: a core of safety shared by every form, and a form for each kind of work.
- [The release loop](concept-release-loop.md): how versions are raised, tagged and published.
