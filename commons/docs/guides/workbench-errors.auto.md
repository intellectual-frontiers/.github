# Errors of the workbench, and what to do

Generated by `commons/workbench/tools/pages.ts` from the code of the library `workbench`; do not edit it.

Every failure the workbench reports has one code, `E-WB-<CONCEPT>-<KIND>`, belongs to one of the four words (workstation, workshop, workspace, workbench) and has one fix. `bun run workbench explain CODE` says the same as this page. Until 2027-01-01 a finding is only a hint, except a safety rule, which is always an error.

**Who fixes it:** `agent` means the one working can run the fix; `person` means a person must do it (a credential, an approval); `environment` means the owner of the workshop; `ci` means a rebuild.

**A failure that is in none of these** is `E-WB-UNKNOWN`: classify it by adding an entry, a check and a test, and documenting it, in one change.

## Workstation

| Code | What happened | Who fixes it | What it says | The fix |
|---|---|---|---|---|
| `E-WB-WORKSTATION-HARNESS-CONFIG` | The harness is not configured as the contract says | agent | A file a dialect generates for the harness is missing or differs from what the contract makes. | generate it again: workbench project dialect {name} |
| `E-WB-WORKSTATION-AUTHORITY` | The operator lacks a key or identity the task needs | person | A signature, an approval or a login only a person's workstation holds is needed. | do it from your own workstation: {gate} |

## Workshop

| Code | What happened | Who fixes it | What it says | The fix |
|---|---|---|---|---|
| `E-WB-WORKSHOP-MISSING-PROGRAM` | A program the work needs is not here | agent | The task runs a program that is not on the PATH of the workshop. | install {name}: {install} |
| `E-WB-WORKSHOP-WRONG-VERSION` | A program is older than the task needs | agent | The program is here, at a version below the least the task names. | install {name} at {minimum} or later: {install} |
| `E-WB-WORKSHOP-NETWORK-REFUSED` | The network refuses what the task needs | environment | A host the task reaches is not allowed from this workshop, or refuses the kind of request (a write, a new branch, a tag). | ask the owner of the environment to allow {host}, or do this part where it is allowed |
| `E-WB-WORKSHOP-DRIFT` | The workshop is not what its contract makes | ci | A cold build of the workshop from the contract is not the workshop that is running. | rebuild the workshop from the contract and compare |

|---|---|---|---|---|
| `E-WB-WORKSPACE-GIT-STATE` | The repository is not in the state the task assumes | agent | A ref the task compares with is missing (a shallow clone with no origin/main) or the Git identity is not set. | fetch what is missing: git fetch --depth 50 origin {ref} |
