# Feature Specification: Greeting

**Feature Branch**: `001-greeting` **Created**: 2026-11-16 **Status**:
Implemented **Input**: Greet a person by name, in one line.

## Requirements

- **FR-001** A greeting names the person it greets.
- **FR-002**: A greeting is one line,
  and ends with a full stop.

## Success criteria

- **SC-001** `greet("Ada")` says `Hello, Ada.`
